# Regras do Projeto NexusOS

## Manutenção da Documentação
Sempre que uma nova funcionalidade, rota de API, alteração de banco de dados (migração), refatoração relevante ou novo módulo for implementado no **NexusOS**:

1. **Atualização Obrigatória:** A documentação viva em `docs/DOCUMENTACAO_GERAL.md` DEVE ser atualizada.
2. **Changelog:** Adicione uma nova entrada na secção "7. Registro de Alterações (Changelog Automático)" com a data atual, detalhando as mudanças efetuadas.
3. **Módulos / Endpoints / Schema:** Se novas tabelas, campos ou rotas forem adicionados, atualize as respetivas secções de arquitetura e módulos.
